## 删除光标所在单词

将光标移动到单词的任意位置，然后输入：

```
diw
```

| 命令  | 英文含义   | 作用       |
| --- | ------ | -------- |
| `d` | Delete | 删除文本     |
| `i` | Inner  | 表示文本对象内部 |
| `w` | Word   | 表示当前单词   |
无论光标在单词的哪个字符上，`diw` 都可以删除整个单词，同时保留周围的空格。

---

另外一种方式是进入可视模式（**在 Neovim中，可视模式（Visual Mode）就是用来选中文本的模式**）你可以把可视模式看作是在vscode中用鼠标选中整行。但 Vim 的可视模式更强大，因为它可以结合 Vim 的光标移动命令，快速选中单词、代码块、函数等内容。
### Visual Mode 三种模式
| 模式     | 进入方式       | 用途        |
| ------ | ---------- | --------- |
| 字符可视模式 | `v`        | 按字符选中文本   |
| 行可视模式  | `V`        | 按整行选中文本   |
| 块可视模式  | `Ctrl + v` | 按矩形区域选中文本 |

删除方式：

```
viwd
```

| 命令 | 含义   | 作用                             |
| ---- | ------ | -------------------------------- |
| `v`  | Visual | 进入字符可视模式                 |
| `i`  | Inner  | 表示选择对象内部，不包含周围空格 |
| `w`  | Word   | 指定文本对象为单词               |
| `d`  | Delete | 删除选中的内容                   |

## 在单词间移动
|按键|英文含义|作用|
|---|---|---|
|`w`|Word|向前移动到下一个单词的开头|
|`b`|Backward|向后移动到上一个单词的开头|
|`e`|End|向前移动到当前或下一个单词的结尾|
|`ge`|Go to End|向后移动到上一个单词的结尾|

所以，**想移动到单词末尾并在后面输入，用 `ea`**：先按 `e`，再按 `a`。

## 遇到E325: ATTENTION（交换文件冲突）
E325: ATTENTION（交换文件冲突）这种情况一般出现在当你没有在nvim进行保存和正常退出会出现。报错如下图所示：
![[Pasted image 20261109132216.png]]
解决方案：
### 第一步：退出当前警告

按Q，或者如果还在 Neovim 中，可以使用 `:q` 退出当前窗口。回到普通终端后进行下面的操作。
### 第二步：检查 Neovim 进程

如果没有输出对应进程，说明创建交换文件的进程已经不存在。
如果进程还在，先找到对应的 Neovim 窗口，保存并正常退出。不要直接删除仍在使用的交换文件。
```shell
ps -p 4185 -o pid,command
```

### 第三步：检查是否存在未保存的代码

检查恢复出的代码是否有需要保留的内容。如果有，先另外保存一份，或者确认恢复内容后执行 `:w`。
```shell
cd ~/tianyi-knowledge-base/exercise
nvim -r main.c
```

### 第四步：删除遗留交换文件

在确认没有其他进程使用它、也不再需要恢复内容后，执行：

```shell
rm -- "$HOME/.local/state/nvim/swap/%Users%tianyi%tianyi-knowledge-base%exercise%main.c.swp"
```

## 全选的快捷键

```
ggVG
```

需要在**普通模式（Normal Mode）下执行，先按 `Esc`。

|按键|作用|
|---|---|
|`gg`|跳转到文件第一行|
|`V`|进入行可视模式（Visual Line Mode）|
|`G`|跳转到文件最后一行|
|`ggVG`|全选整个文件|

### 常见配套操作

| 操作          | 快捷键       |     |
| ----------- | --------- | --- |
| 全选          | `ggVG`    |     |
| 全选并复制       | `ggVGy`   |     |
| 全选并删除       | `ggVGd`   |     |
| 全选并缩进       | `ggVG>`   |     |
| 全选并取消缩进     | `ggVG<`   |     |
| 全选并复制到系统剪贴板 | `ggVG"+y` |     |

## 语法错误快速查看

可以在在带红色错误标记的行上，**按 `Esc`，再依次按 `空格 → c → d`**，就会弹出具体错误信息。这几个键是依次按，不是同时按。

| 操作        | 普通模式按键      |     |
| --------- | ----------- | --- |
| 查看当前行错误详情 | `空格 c d`    |     |
| 下一个／上一个诊断 | `]d` ／ `[d` |     |
| 下一个／上一个错误 | `]e` ／ `[e` |     |
| 打开／关闭问题列表 | `空格 x x`    |     |

左侧红色表示错误，黄色表示警告。之前为了保持界面干净，关闭了直接显示在代码旁边的诊断文字。

## 在nvim打开命令行

按 `Esc` 回到普通模式，输入下面命令并回车，就能在**右侧打开终端**：

```
:vsplit | terminal
```

常用操作：

- **输入命令**：在终端窗口按 `i`。
- **退出终端输入模式**：连按两次 `Esc`。
- **切回左侧代码**：`Ctrl+h`。
- **切到右侧终端**：`Ctrl+l`。
- **关闭终端窗口**：退出输入模式后输入 `:q!`，会同时结束里面的命令行。

## a与i的区别

在 **Normal 模式**下：

- **`i`（insert）**：在当前字符的**前面**开始输入。
- **`a`（append）**：在当前字符的**后面**开始输入。

例如光标停在 `b` 上，`|` 表示输入位置：

```
原来：a[b]c
按 i：a|bc
按 a：ab|c
```

对应的大写键：**`I` 到行首第一个非空字符前输入，`A` 到行尾输入。**
