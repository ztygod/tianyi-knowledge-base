在 Obsidian（Mac） 中，常用快捷键如下：

|功能|Mac 快捷键|说明|
|---|---|---|
|保存笔记|`⌘ + S`|手动保存当前笔记|
|打开命令面板|`⌘ + P`|搜索并执行 Obsidian 命令|
|快速切换笔记|`⌘ + O`|搜索并打开笔记|
|全局搜索|`⌘ + Shift + F`|搜索整个知识库|
|新建笔记|`⌘ + N`|创建新的 Markdown 笔记|
|打开设置|`⌘ + ,`|打开 Obsidian 设置|
|切换编辑/阅读视图|`⌘ + E`|在编辑与阅读模式间切换|

## 关于保存笔记

Obsidian 默认自动保存，不需要像 VS Code 一样经常按 `⌘ + S`。

只要你修改笔记，Obsidian 就会自动将内容写入本地 Markdown 文件。

但要注意：自动保存不等于自动同步到 GitHub。 如果你使用 Obsidian Git 插件，可以通过命令面板执行 `Obsidian Git: Create backup` 来提交并推送笔记，具体命令名称以安装版本为准。

## 正向链接与反向链接

### **1. 创建正向链接**

在任意笔记中输入两个左方括号 `[[`，Obsidian 就会弹出笔记搜索列表。常用语法：

|语法|效果|
|---|---|
|`[[进程]]`|链接到进程笔记|
|`[[进程\\|Process]]`|显示为 Process，实际链接到进程|
|`[[进程#进程状态]]`|链接到进程笔记的指定标题|
|`[[进程#^block-id]]`|链接到指定文本块|
|`![[进程]]`|直接嵌入进程笔记的内容|

其中，`![[进程]]` 非常实用，它不是普通的跳转，而是直接在当前笔记中展示另一篇笔记的内容。

### **2. 查看反向链接**

在 Obsidian 中：

1. 打开「设置 → 核心插件（Core plugins）」。
2. 确保 **Backlinks（反向链接）** 已启用。
3. 打开命令面板 `Cmd + P`（Mac），搜索 `Backlinks: Show backlinks`。
4. 就可以查看当前笔记被哪些其他笔记引用。

还可以通过命令 `Backlinks: Toggle backlinks in document`，让反链直接显示在当前笔记底部。
