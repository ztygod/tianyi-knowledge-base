在 Obsidian（Mac） 中，常用快捷键如下：

|功能|Mac 快捷键|说明|
|---|---|---|
|保存笔记|`⌘ + S`|手动保存当前笔记|
|打开命令面板|`⌘ + P`|搜索并执行 Obsidian 命令|
|快速切换笔记|`⌘ + O`|搜索并打开笔记|
|全局搜索|`⌘ + Shift + F`|搜索整个知识库|
|新建笔记|`⌘ + N`|创建新的 Markdown 笔记|
|打开设置|`⌘ + ,`|打开 Obsidian 设置|
|切换编辑/阅读视图|`⌘ + E`|在编辑与阅读模式间切换|

### 关于保存笔记

Obsidian 默认自动保存，不需要像 VS Code 一样经常按 `⌘ + S`。

只要你修改笔记，Obsidian 就会自动将内容写入本地 Markdown 文件。

但要注意：自动保存不等于自动同步到 GitHub。 如果你使用 Obsidian Git 插件，可以通过命令面板执行 `Obsidian Git: Create backup` 来提交并推送笔记，具体命令名称以安装版本为准。
