## **C++ 类型系统（Type System）**

### **基本数据类型**

C++ 是静态类型语言，变量的类型通常在编译阶段就已经确定。**类型不只是对数据的分类，更是编译器解释和操作数据的一种规则。**

### `auto` **类型推导**

现代 C++ 中，可以使用 `auto` 让编译器自动推导变量类型。

```java
auto a = 10;       // int
auto b = 3.14;     // double
auto c = 3.14f;    // float
auto d = true;     // bool
auto e = 'A';      // char
```

需要注意，C++ 的 `auto` 并不意味着动态类型。

```java
auto x = 10;
x = 3.14;
```

这里 `x` 仍然是 `int` 类型，赋值时会发生类型转换，最终存储的值为 `3`。
