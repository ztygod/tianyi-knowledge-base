## **从第一性原理理解内存与指针**

### 什么是变量

假设我们定义一个变量：

```c++
int a = 10;
```

从语言层面来看，我们创建了一个名为 `a`、类型为 `int`、值为 `10` 的对象。从内存角度来看，可以将其理解为程序拥有了一块用于存储整数的内存空间，并通过名称 `a` 访问这块空间。

### **如何获取变量的内存地址**

C++ 提供了取地址运算符 `&`。

```c++
#include <iostream>

int main() {
    int a = 10;
    std::cout << a << '\n';
    std::cout << &a << '\n';
}
```

其中：

- `a` 表示访问对象的值。
- `&a` 表示获取对象的地址。

**那么，如果我们希望将这个地址保存起来，应该使用什么类型？答案就是指针**。

### **什么是指针（Pointer）**

**指针是一种能够保存地址的类型，通过指针可以间接访问其所指向的对象。**

```c++
int a = 10;
int* p = &a;
```

这里创建了两个对象：

- `a`：存储整数 `10`。
- `p`：存储 `a` 的地址。

需要特别注意：**指针本身也是一个对象，也有自己的地址和存储空间。**

### **解引用（Dereference）**

如果已经获得了一个对象的地址，如何访问这个地址对应的对象？

使用解引用运算符 `*`。

```c++
int a = 10;
int* p = &a;

std::cout << *p << '\n'; // 10
*p = 20;
std::cout << a << '\n';  // 20
```

`*p` 并不是复制一份 `a`，而是通过地址访问 `a` 本身。

## 引用

### 为什么需要引用

假设我们希望通过另一个名称访问变量 `a`。使用指针可以做到：

```c++
int a = 10;
int* p = &a;
*p = 20;
```

但是每次访问都需要解引用。C++ 提供了另一种语言机制：引用。

```c++
int a = 10;
int& ref = a;

ref = 20;
std::cout << a << '\n'; // 20
```

**引用是已有对象的别名（Alias）。** 引用一旦绑定到某个对象，就不能重新绑定到其他对象。

## **函数参数传递机制**

### **值传递（Pass by Value）**

```c++
void modify(int x) {
    x = 100;
}

int main() {
    int a = 10;
    modify(a);
    std::cout << a << '\n'; // 10
}
```

函数调用时，**形参 `x` 使用实参 `a` 的值进行初始化**。对于这里的 `int`，两者是独立的对象。

### **引用传递（Pass by Reference）**

```c++
void modify(int& x) {
    x = 100;
}

int main() {
    int a = 10;
    modify(a);
    std::cout << a << '\n'; // 100
}
```

此时 `x` 是 `a` 的引用，而不是一个独立的整数副本。

### **指针传递（Pass by Pointer）**

```c++
void modify(int* x) {
    if (x != nullptr) {
        *x = 100;
    }
}

int main() {
    int a = 10;
    modify(&a);
    std::cout << a << '\n'; // 100
}
```

这里有一个非常重要的细节：**指针传递本质上仍然是值传递，只不过复制的值是地址。**

## **const：限制修改权限**

### **为什么需要 const？**

假设我们编写一个打印矩阵的函数：

```c++
void show(Matrix matrix);
```

但是，**我们不希望复制整个矩阵，也不希望函数修改原始矩阵**。

此时就可以使用：

```c++
void show(const Matrix& matrix);
```

它同时实现了两个目的：
- `&`：通过引用访问原始对象，避免拷贝。
- `const`：限制函数通过该引用修改对象。

### **const 与指针**

这里有三种非常重要的形式。

```c++
int a = 10;
int b = 20;

const int* p1 = &a;
int* const p2 = &a;
const int* const p3 = &a;
```

#### **第一种：Pointer to Const（指向常量的指针）**

```c++
const int* p = &a;

p = &b;  // 合法
*p = 30; // 编译错误
```

指针自身可以改变指向，但不能通过该指针修改对象。

#### **第二种：Const Pointer（常量指针）**

```c++
int* const p = &a;

*p = 30; // 合法
p = &b;  // 编译错误
```

指针自身不能改变指向，但是可以通过它修改对象。

#### **第三种：Const Pointer to Const**

```c++
const int* const p = &a;

*p = 30; // 编译错误
p = &b;  // 编译错误
```

两种修改都不允许。


## 常见内存错误

### **内存泄漏（Memory Leak）**

```c++
void foo() {
    int* p = new int{10};
}
```

当函数结束时，局部指针 `p` 的生命周期结束，但是动态分配的整数对象没有被释放。如果没有其他可用指针保存其地址，程序就失去了访问和释放这块内存的途径。

正确的手动管理方式：

```c++
void foo() {
    int* p = new int{10};
    delete p;
}
```

### **悬空指针（Dangling Pointer）**

指针所指向对象的生命周期已经结束，但指针仍然保存着原来的地址。

```c++
int* p = new int{10};
delete p;

std::cout << *p; // Undefined Behavior
```

这种错误又称为 Use After Free（释放后使用）。

### **为什么现代 C++ 不推荐大量使用 new/delete？**

现代 C++ 更推荐使用 RAII 和标准库提供的资源管理类型。

```c++
#include <memory>

int main() {
    auto p = std::make_unique<int>(10);
    // 自动释放资源
}
```

或者使用容器：

```c++
std::vector<int> arr(100);
```

我们现在学习 `new/delete`，是为了理解底层资源管理机制，而不是为了在之后的所有项目中手动管理内存。
