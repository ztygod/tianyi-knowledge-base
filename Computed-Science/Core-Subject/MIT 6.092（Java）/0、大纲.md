这门课程是 MIT 开设的 Java 入门编程课程，主要目标是让学生掌握 Java 基础语法、面向对象编程思想，以及使用 Java 独立解决实际编程问题的能力。

# MIT 6.092 学习大纲

## 1. Java 程序基础（Java Fundamentals）

- [ ] JDK、JRE、JVM 的关系
- [ ] Java 程序的编译与运行机制
- [ ] Java 程序的基本结构
- [ ] main 方法
- [ ] 基本数据类型（Primitive Types）
- [ ] 变量与常量
- [ ] 运算符与类型转换

**实践任务：** Assignment 1：GravityCalculator

**验收标准：** 理解 Java 程序从源代码到运行的过程，能够独立编写基础程序。

## 2. 方法与控制流（Methods and Control Flow）

- [ ] 方法的定义与调用
- [ ] 参数与返回值
- [ ] 方法重载（Overloading）
- [ ] 变量作用域
- [ ] String 类型
- [ ] 条件判断
- [ ] Java 的值传递机制

**实践任务：** Assignment 2：FooCorporation

**验收标准：** 能够使用方法拆分程序逻辑，理解 Java 的参数传递方式。

## 3. 循环与数组（Loops and Arrays）

- [ ] for、while、do-while
- [ ] 增强 for 循环
- [ ] 一维数组与二维数组
- [ ] 数组的初始化与遍历
- [ ] 数组的引用语义
- [ ] 基本类型与引用类型的区别

**实践任务：** Assignment 3：Marathon

**验收标准：** 能够独立使用数组解决基础算法问题。

## 4. 类与对象（Classes and Objects）

- [ ] 面向对象编程的基本思想
- [ ] Class 与 Object
- [ ] 实例变量与实例方法
- [ ] 构造函数（Constructor）
- [ ] this 关键字
- [ ] static 关键字
- [ ] 对象的创建与引用
- [ ] 对象的生命周期与垃圾回收
- [ ] null 与对象引用

**实践任务：** Assignment 4：Library

**验收标准：** 能够独立设计多个类，并理解对象之间的交互关系。

## 5. 封装、作用域与包（Encapsulation and Packages）

- [ ] public、private、protected
- [ ] 默认访问权限
- [ ] 封装（Encapsulation）
- [ ] 类作用域与实例作用域
- [ ] static 与 final
- [ ] package 与 import
- [ ] Java API 与标准库
- [ ] 多文件 Java 项目的组织方式

**实践任务：** Assignment 5：Graphics!

**验收标准：** 能够组织具有多个类和包的 Java 项目，合理控制数据的访问权限。

## 6. 程序设计、接口与调试（Design, Interfaces and Debugging）

- [ ] 良好的类与方法设计
- [ ] 抽象（Abstraction）
- [ ] 接口（Interface）
- [ ] implements 关键字
- [ ] 面向接口编程
- [ ] 多态（Polymorphism）
- [ ] 断点与 Debugger
- [ ] 断言（Assertions）
- [ ] 基本测试方法

**实践任务：** Assignment 6：Graphics strikes back!

**验收标准：** 理解接口存在的意义，能够利用接口降低不同模块之间的耦合。

## 7. 继承、异常与文件操作（Inheritance, Exceptions and I/O）

- [ ] 继承（Inheritance）
- [ ] extends 与 super
- [ ] 方法重写（Overriding）
- [ ] 抽象类（Abstract Class）
- [ ] 动态绑定
- [ ] 异常处理机制
- [ ] try、catch、finally
- [ ] throw 与 throws
- [ ] 文件读取与写入

**实践任务：** Assignment 7：Magic Squares

**验收标准：** 能够利用继承与多态组织程序，并独立处理文件和异常。

## 8. 现代 Java 与数据结构基础（Modern Java and Collections）

- [ ] 泛型（Generics）
- [ ] 包装类型与自动装箱
- [ ] ArrayList 与 LinkedList
- [ ] HashMap 与 HashSet
- [ ] Iterator 与 Iterable
- [ ] Comparable 与 Comparator
- [ ] equals 与 hashCode
- [ ] JUnit 基础测试

**实践任务：** 补充实验：实现一个泛型链表

**验收标准：** 具备继续学习 CS61B 和开发 Java 解释器所需要的基础能力。
