## **Interface：接口**

### **什么是 Interface？**

Java 中的接口是一种定义行为契约的机制。我们可以把刚才的 Shape 抽象定义为一个接口：

```java
interface Shape {
    void draw();
}
```

这个接口表达了一个要求：

任何实现 Shape 的类，都必须提供符合要求的 `draw()` 方法实现。例如：

```java
class Circle implements Shape {
    public void draw() {
        System.out.println("Drawing circle");
    }
}

class Rectangle implements Shape {
    public void draw() {
        System.out.println("Drawing rectangle");
    }
}
```

这里出现了一个新关键字：`implements` 它表示一个类实现某个接口。Shape 规定能力，Circle 和 Rectangle 分别提供实现。

注意：接口中的普通抽象方法默认是 `public abstract`，实现类必须提供 `public` 实现，不能降低访问权限。

### **Interface 与 Class 的区别**

| 对比   | Interface     | Class      |
| ---- | ------------- | ---------- |
| 主要目的 | 定义行为契约        | 描述具体对象及其实现 |
| 实例字段 | 不能有普通实例字段     | 可以有        |
| 构造函数 | 不可以有          | 可以有        |
| 实例方法 | 可以声明抽象方法及默认方法 | 可以有        |
| 实例化  | 不能直接实例化       | 可以创建具体类对象  |
| 继承关系 |               | 一个直接父类     |
现代 Java 接口还支持：

- `default` 方法：提供默认实现。
- `static` 方法：属于接口本身。
- `private` 方法：供接口内部方法复用。
- 常量：接口字段隐式为 `public static final`。

### **一个类可以实现多个接口**

Java 的类只能直接继承一个类，但可以实现多个接口。

```java
interface Drawable {
    void draw();
}

interface Movable {
    void move();
}

class GameObject implements Drawable, Movable {
    public void draw() {
        System.out.println("Drawing");
    }

    public void move() {
        System.out.println("Moving");
    }
}
```

这意味着 GameObject 同时具备绘制和移动两种能力。

## **多态（Polymorphism）**

==🟡Java 多态就是：**父类引用可以指向不同的子类对象，当调用同一个方法时，会根据实际对象的类型执行不同的实现。**==

### **什么是多态？**

先看一段代码：

```java
Shape circle = new Circle();
Shape rectangle = new Rectangle();
```

这里有一个看似矛盾的地方：左边的类型是 `Shape`，右边创建的对象却分别是 `Circle` 和 `Rectangle`。为什么允许这样写？

因为 Circle 和 Rectangle 都实现了 Shape 接口。**因此，Shape 类型的引用可以指向任何实现 Shape 的对象**。这就是多态（Polymorphism）的基础。

### **多态真正有价值的地方：统一处理不同对象**

假设我们有 100 种不同图形。没有多态时，你可能写出这样的代码：

```Java
if (shapeType.equals("circle")) {
    drawCircle();
} else if (shapeType.equals("rectangle")) {
    drawRectangle();
} else if (shapeType.equals("triangle")) {
    drawTriangle();
}
```

每增加一种图形，就需要修改这段代码。使用接口：

```Java
void render(Shape shape) {
    shape.draw();
}
```

无论传入 Circle、Rectangle 还是 Triangle，都可以调用：

```java
render(new Circle());
render(new Rectangle());
render(new Triangle());
```

使用者不需要知道具体对象的类型。**多态让不同实现能够通过统一接口被处理。**
