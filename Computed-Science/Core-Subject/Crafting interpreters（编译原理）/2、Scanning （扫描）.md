## **词素（Lexeme）、词法单元（Token）和字面值（Literal Value）**

在编译原理中，**词素（Lexeme）、词法单元（Token）和字面值（Literal Value）** 是词法分析（Lexical Analysis）中的三个重要概念。

它们的核心区别是：

- 词素（Lexeme）：源代码中实际出现的字符序列。
- 词法单元（Token）：词法分析器识别出来的语法单位，通常**包含类型、词素**等信息。在Lox编程语言中，词法单元就包括了词素，Token 类型，字面值和行号等信息

```java
class Token {
    final TokenType type;
    final String lexeme;
    final Object literal;
    final int line;
}
```

- 字面值（Literal Value）：字面量在程序中表示的实际值。

假设我们有一段 Lox 代码：

```
var age = 18;
```

词法分析器会将它拆分成以下 Token：

|词素（Lexeme）|Token 类型（Token Type）|字面值（Literal Value）|
|---|---|---|
|`var`|VAR|null|
|`age`|IDENTIFIER|null|
|`=`|EQUAL|null|
|`18`|NUMBER|18.0|
|`;`|SEMICOLON|null|

这里的 `18` 是源代码中的字符序列，而 `18.0` 是词法分析器解析之后得到的数值。

## Reserved Words and Identifiers （保留字与标识符）

保留字是编程语言预先规定不能用于普通命名的单词。标识符是程序员为变量、函数、类等定义的名称。例如，在 Lox 语言中：

```
var age = 18;
if (age > 10) {
    print age;
}
```

其中：

- `var`：声明变量的关键字。
- `if`：条件判断的关键字。
- `print`：输出语句的关键字。

这些词都有特定的语法作用，不能作为变量名。

|英文|中文|含义|
|---|---|---|
|Reserved Words|保留字|编程语言预先保留的单词，不能用作普通标识符|
|Identifiers|标识符|程序员定义的名称，例如变量名、函数名、类名|

## **最长匹配**

**当两条词法语法规则都能匹配扫描器正在查看的一段代码时， 匹配字符最多的那条规则胜出。** 该规则指出，如果我们既能将 `orchid` 匹配为标识符，又能将 `or` 匹配为关键字，那么前者胜出。这也是为什么我们之前默认认为 `<=` 应被扫描为单个 `<=` 词法单元，而不是 `<` 后跟 `=`。

根据最长匹配原则，词法分析器必须先读取完整的单词，才能判断它是保留字还是普通标识符。

例如，遇到 `var` 时，不能立即判断它是保留字，因为后面可能还有其他字符，组成 `variable` 这样的普通标识符。

实际上，保留字和普通标识符遵循相同的字符组成规则，区别在于：保留字已经被编程语言赋予了特殊含义，因此不能再被程序员用作普通标识符。这也是它被称为“保留字”的原因。
