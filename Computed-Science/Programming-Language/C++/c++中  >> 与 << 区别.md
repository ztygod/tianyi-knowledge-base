在 C++ 中，`>>` 和 `<<` 都是运算符，它们的含义取决于使用场景。

**在 Stream（流）中，**`>>` **用于读取数据，**`<<` **用于写入数据；在整数运算中，它们分别表示右移和左移。**

## **一、在 Stream 中的区别**

|运算符|名称|作用|数据流向|
|---|---|---|---|
|`>>`|提取运算符（Extraction Operator）|从流中读取数据|Stream → 变量|
|`<<`|插入运算符（Insertion Operator）|向流中写入数据|变量 → Stream|

### **1.** `>>`**：读取数据**

```
#include <iostream>
using namespace std;

int main() {
    int age;
    cin >> age;
    cout << age;
}
```

其中：

```
cin >> age;
```

表示从标准输入流 `cin` 中提取数据，经过必要的类型转换后，赋值给变量 `age`。

### **2.** `<<`**：写入数据**

```
int age = 20;
cout << age;
```

其中：

```
cout << age;
```

表示将整数 `20` 转换成适合输出的字符序列，写入标准输出流 `cout`。

## **二、结合 stringstream 理解**

```c++
#include <iostream>
#include <sstream>
using namespace std;

int main() {
    stringstream ss;

    // 写入数据
    ss << 100 << " " << 200;

    // 读取数据
    int a, b;
    ss >> a >> b;

    cout << a + b << endl; // 300
}
```

## **三、为什么可以连续使用？**

例如：

```
cout << 10 << 20;
cin >> a >> b;
```

**这是因为流的插入和提取运算符通常会返回对流对象自身的引用。**

例如：

```
cout << 10 << 20;
```

可以理解为：

```
(cout << 10) << 20;
```

第一次 `cout << 10` 返回 `cout` 的引用，因此还能继续执行 `<< 20`。

## **四、它们还可以表示位运算**

在整数运算中：

```
int a = 8;

cout << (a >> 1) << endl; // 4
cout << (a << 1) << endl; // 16
```

对于这里的非负整数：

- `8 >> 1`：二进制向右移动一位，结果为 `4`。
    
- `8 << 1`：二进制向左移动一位，结果为 `16`。
    

因此，**同样的运算符，作用于不同类型的操作数时，含义可能不同**。Stream 中的 `>>`、`<<` 是通过 C++ 运算符重载实现的。

总结：学习 C++ Stream 时，记住 `>>` 是从流中提取数据，`<<` 是向流中插入数据即可。理解箭头所表达的数据流向，比单纯记住符号方向更重要。
