## 一、先一句话总结

_**Rust**_ _**的闭包（Closure）是一种能够捕获外部**__**环境变量**__**的**__**匿名函数**__**，本质上可以理解为一个实现了**_ _**`Fn`**__**、**__**`FnMut`**_ _**或**_ _**`FnOnce`**_ _**Trait 的匿名结构体**_。

相比普通函数，**闭包最大的特点是能够自动捕获定义它时所在****作用域****中的变量**，并且可以作为函数参数或返回值使用。

## 二、核心要点

### 1. 闭包的基本语法

Rust 使用 `|参数|` 定义闭包：

```Rust
fn main() {
    let add = |a: i32, b: i32| a + b;
    println!("{}", add(1, 2)); // 3
}
```

闭包与普通函数的区别在于，闭包通常可以省略参数和返回值类型，由编译器根据上下文进行类型推断。

### 2. 闭包如何捕获外部变量

这是 Rust 闭包最重要的特点。

闭包可以通过三种方式捕获外部变量：

|   |   |   |
|---|---|---|
|捕获方式|说明|示例|
|不可变借用 &T|读取外部变量，不修改|Fn|
|可变借用 &mut T|可以修改外部变量|FnMut|
|获取所有权 T|将值移动到闭包内部|常见于 move 闭包|

例如：

```Plain
fn main() {
    let name = String::from("Rust");

    let greet = || {
        println!("Hello, {}", name);
    };

    greet();
    println!("{}", name);
}
```

这里闭包使用了外部变量 `name`，但没有修改它，所以编译器通常会选择不可变借用，而不会转移所有权。

如果闭包需要修改外部变量：

```Rust
fn main() {
    let mut count = 0;

    let mut increment = || {
        count += 1;
    };

    increment();
    increment();

    println!("{}", count); // 2
}
```

这里闭包需要修改 `count`，因此会通过可变借用捕获它。

一句话总结：Rust 编译器会根据闭包内部对外部变量的使用方式，决定如何捕获变量。

### 3. 闭包的三个核心 Trait：Fn、FnMut、FnOnce

这是面试中最容易被追问的知识点。

Rust 使用三个 Trait 描述闭包的调用能力：

|   |   |   |
|---|---|---|
|Trait|核心含义|调用方式|
|Fn|调用时不需要修改或消耗捕获的环境|可以重复调用|
|FnMut|调用时可能需要修改捕获的环境|可以重复调用，需要可变访问|
|FnOnce|调用时允许消耗捕获的变量|至少支持调用一次|

需要特别注意：这三个 Trait 并不是与三种捕获方式严格一一对应的。

它们存在继承关系：

也就是说：

- 实现 `Fn` 的闭包，也实现 `FnMut` 和 `FnOnce`。
    
- 实现 `FnMut` 的闭包，也实现 `FnOnce`。
    
- 只实现 `FnOnce` 的闭包，不一定实现另外两个 Trait。
    

例如：

```Rust
fn main() {
    let value = String::from("hello");

    let consume = move || {
        drop(value);
    };

    consume();
    // consume(); // 编译错误
}
```

这个闭包通过 `move` 获取了 `value` 的所有权，又在调用时通过 `drop(value)` 消耗了它，因此只能调用一次。

一句话总结：闭包实现哪种 Trait，关键取决于调用时如何使用捕获的变量，而不只是捕获方式。

### 4. move 关键字的作用

`move` 会_**强制闭包按值捕获其使用的外部变量，而不是通过引用捕获**_。

```Plain
fn main() {
    let name = String::from("Rust");

    let closure = move || {
        println!("{}", name);
    };

    closure();
    // println!("{}", name); // 编译错误
}
```

因为 `String` 不实现 `Copy`，所以 `name` 的所有权被移动到了闭包内部。

但是要注意：

`move` 闭包不一定是 `FnOnce`。

上面的闭包只读取了 `name`，没有在调用时消耗它，因此可以重复调用，仍然能够实现 `Fn`。

`move` 经常用于多线程场景，因为线程可能比当前函数存活得更久，需要将数据所有权转移到线程内部。

## 三、补充理解：闭包底层是如何实现的？

_**Rust 的闭包在编译时通常会被转换成一个匿名结构体。**_

例如：

```Plain
let x = 10;
let closure = |y: i32| x + y;
```

可以近似理解为：

```Plain
struct Closure<'a> {
    x: &'a i32,
}

impl FnOnce<(i32,)> for Closure<'_> {
    // 调用时计算 self.x + y
}
```

这里省略了实际的 Trait 方法实现细节，因为 `FnOnce` 的手动实现涉及特殊的编译器特性，不能直接在稳定版 Rust 中按这个形式编写。

编译器大致做了两件事：

1. 生成一个匿名结构体，把捕获的变量作为结构体字段。
    
2. 根据闭包内部的使用方式，自动实现对应的 `Fn`、`FnMut` 或 `FnOnce` Trait。
    

因此，闭包并不需要把捕获的变量放到全局环境中，本质上是把这些变量作为自身状态保存起来。

这也是 Rust 闭包能够携带环境状态，并且在编译期检查所有权和生命周期的原因。

## 四、使用场景

闭包在 Rust 中最常见的使用场景是迭代器、回调函数和多线程。

例如，迭代器中的 `map`：

```Plain
fn main() {
    let nums = vec![1, 2, 3];

    let result: Vec<i32> = nums
        .iter()
        .map(|x| x * 2)
        .collect();

    println!("{:?}", result); // [2, 4, 6]
}
```

还可以使用泛型 Trait Bound 接收闭包：

```Plain
fn execute<F>(f: F)
where
    F: FnOnce(),
{
    f();
}

fn main() {
    let name = String::from("Rust");

    execute(|| {
        println!("{}", name);
    });
}
```

这里的 `F: FnOnce()` 表示函数可以接收任意实现了 `FnOnce` 的闭包。

由于 `Fn` 和 `FnMut` 都继承了 `FnOnce`，所以这个函数实际上能够接收三种调用能力的闭包。

## 五、面试完整答案（可以直接背）

Rust 的闭包是一种可以捕获外部环境变量的匿名函数。

相比普通函数，闭包最大的特点是能够使用定义它的作用域中的变量_**。Rust 编译器会根据变量的使用方式，自动选择不可变借用、可变借用或者获取所有权这三种捕获方式。**_

_**从底层实现来看，Rust 编译器会为闭包生成一个匿名结构体，将捕获的变量保存为结构体字段，并根据闭包内部的操作自动实现**_ _**`Fn`**__**、**__**`FnMut`**_ _**或**_ _**`FnOnce`**_ _**Trait。**_

这三个 Trait 主要描述闭包的调用能力：`Fn` 可以通过共享引用重复调用，`FnMut` 可以通过可变引用重复调用，而 `FnOnce` 允许在调用过程中消耗捕获的数据。

另外，Rust 还提供了 `move` 关键字，可以让闭包按值捕获外部变量，经常用于多线程等需要转移数据所有权的场景。

实际开发中，我主要会在迭代器的 `map`、`filter`，以及回调函数、多线程任务中使用闭包。

## 六、加分一句

如果面试官进一步追问闭包和普通函数的区别，可以补充：

Rust 的普通函数不能直接捕获外部局部变量，而闭包可以。并且闭包通常会被编译器转换成携带环境状态的匿名结构体，通过 Trait 实现调用，因此 Rust 的闭包通常不需要额外的动态分配，也不一定存在动态分发开销。

另外，不捕获外部变量的闭包还可以转换成普通函数指针 `fn`，这是 Rust 闭包与函数指针之间一个很值得了解的细节。
